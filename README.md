## 🚀 Featured Projects

### 🛡️ Hybrid Malware Detection System

A multi-modal AI-powered malware analysis platform that combines
**static analysis, dynamic behavior analysis, and memory forensics**
to provide a comprehensive malware assessment.

**Highlights**

- Static PE / `.exe` analysis using **ResNet50**
- Dynamic behavior analysis using **BiLSTM**
- Memory forensics using **XGBoost**
- Multi-modal **272-dimensional feature fusion**
- **Grad-CAM** explainability for static analysis
- Analyst authentication and investigation history
- Automated HTML / JSON reports
- Flask-based web application
- Cloud deployment

**Tech Stack**

`Python` `Flask` `TensorFlow` `Keras` `ResNet50` `BiLSTM`
`XGBoost` `OpenCV` `SQL` `Render`

**Links**

🔗 [GitHub Repository](https://github.com/Sitikanta09/Hybrid-Malware-Detection-System)  
🌐 [Live Demo](https://hybrid-malware-detection-system-qyfo.onrender.com/)

### 🏥 Medical Insurance Cost Prediction

A full-stack machine learning application that predicts estimated
medical insurance costs based on demographic and health-related factors.

**Highlights**

- Insurance cost prediction using **XGBoost Regressor**
- Feature-based prediction using age, BMI, smoking status,
  region, children, and other factors
- User registration and authentication
- Personalized prediction dashboard
- Prediction history and filtering
- Profile and account management
- Input validation and error handling
- Responsive web interface

**Tech Stack**

`Python` `Flask` `XGBoost` `Scikit-learn` `SQLite`
`HTML` `CSS` `JavaScript`

**Links**
